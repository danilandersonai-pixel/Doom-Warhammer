# Решения

Каждая строка — что выбрано и почему.

- **Three.js 0.160.0 с jsdelivr через importmap** — фиксированная версия, без сборки; importmap поддерживается в Safari 16.4+.
- **Код разбит на модули в `src/`** — по файлу на систему, чтобы новичку было проще найти нужное.
- **Только MeshLambertMaterial, 2 источника света + 1 свет вспышки, без теней** — самый дешёвый вариант освещения для 60 FPS на телефоне.
- **Свет вспышки существует всегда, меняется только яркость** — добавление/удаление света заставляет пересобирать шейдеры и даёт фризы.
- **Оружие рисуется отдельной сценой поверх мира (clearDepth)** — так ствол не проваливается в стены.
- **Текстуры рисуются на canvas при запуске** — нет внешних файлов и проблем с авторскими правами.
- **Небо — купол с вертикальным градиентом, цвет горизонта равен цвету тумана** — дальние объекты плавно растворяются в небе.
- **Зубцы стен и мусор — InstancedMesh** — ~100 мелких объектов рисуются за 2 вызова отрисовки.
- **Столкновения — круг против прямоугольников (AABB) в плоскости XZ** — физический движок для такой арены не нужен.
- **Попадания по врагам — луч (Raycaster) по невидимому хитбоксу-коробке** — честнее и быстрее, чем по каждой детали модели.
- **Перед выстрелом обновляем матрицы врагов** — иначе луч мог бить в позицию с прошлого кадра.
- **Частицы — два THREE.Points (обычные и светящиеся) с кольцевым буфером** — пул без создания объектов в каждом кадре.
- **Снаряды врагов — пул из 40 мешей** — то же, без мусора для сборщика.
- **Магазин 24 патрона, общий запас бесконечный** — «ограниченный боезапас» обеспечивает перезарядка, а игрок не может застрять без патронов.
- **Автоперезарядка при пустом магазине + кнопка R** — на телефоне меньше кнопок держать в голове.
- **Броня поглощает урон первой и восстанавливается через 4 с без урона** — без аптечек (их нет в списке фич) бой на 5 минут иначе слишком суров.
- **Обход препятствий врагами — «щупальце» вперёд и поворот на ±45°/90°/135°** — простейший рабочий вариант без навигационной сетки.
- **Стрелок, который не видит игрока, идёт к нему 1.2 с** — чтобы не прятался вечно за колонной.
- **Не больше 7 живых врагов одновременно, появление раз в 0.8 с** — честнее для игрока и легче для телефона.
- **Враги появляются в точках у стен не ближе 11 м от игрока (чемпион — 16 м)** — нельзя получить врага «в спину» из воздуха.
- **Стик появляется там, где коснулся палец (левая половина)** — удобнее фиксированного стика на разных экранах.
- **Кнопкой «Огонь» можно вести пальцем, чтобы одновременно целиться** — на телефоне иначе нельзя стрелять и поворачиваться одной рукой.
- **Отбрасываем движения мыши больше 250 px за событие** — Chrome иногда присылает «прыжок» сразу после захвата курсора, и камера дёргалась.
- **Сенсорный интерфейс включается по `(pointer: coarse)` или наличию touch** — простое определение телефона/планшета.
- **На телефоне pixelRatio ≤ 1.5 и без антиалиасинга** — главный выигрыш в FPS на ретина-экранах.
- **В портретной ориентации FOV 90°, в альбомной 75°** — иначе в портрете обзор слишком узкий.
- **Рестарт без перезагрузки страницы** — не нужно заново разблокировать звук на iOS.
- **Пауза при потере захвата курсора (Esc) и при сворачивании вкладки** — чтобы не умереть, пока не смотришь.
- **Названия врагов нейтральные («враг ближнего боя», «стрелок», «чемпион»), оружие без названия** — без оригинальных названий и лора.
- **Звуки — шум и осцилляторы через Web Audio с компрессором на выходе** — без файлов, наложение многих звуков не хрипит.
- **Проверка в headless Chromium (Playwright) с ботом, проходящим всю игру** — подтверждает поток «волны → чемпион → победа» и «поражение» без ошибок в консоли. Реальный iPhone в этой среде недоступен — нужен ручной тест.
- **Версия одним файлом собирается скриптом `tools/build_artifact.py` в `dist/boltgun.html`** — артефакт публикуется одной страницей, без отдельных модулей; исходники в `src/` остаются главными.

## Визуал в стиле ретро-шутера (вторая итерация)

- **Ориентир — общий стиль Boltgun / Boltgun Boom (пиксели, спрайты, кровь, готика), но вся графика нарисована заново кодом** — по правилам CLAUDE.md оригинальные ассеты, модели и логотипы копировать нельзя.
- **Рендер в низком разрешении (300 px по высоте на ПК, 250 на телефоне) + `image-rendering: pixelated`** — главный приём ретро-вида и заодно сильная экономия GPU на телефоне.
- **Текстуры 64×64 с NearestFilter** — квадратные пиксели без размытия.
- **Враги — плоские спрайты, всегда повёрнутые к камере, 4 кадра (шаг, шаг, замах/прицел, удар/выстрел), смена кадров с низкой частотой** — как в шутерах 90-х. Только вид спереди (без 8 направлений) — проще, а в бою на арене почти не заметно.
- **Спрайты рисуются кодом прямоугольниками + автоматический тёмный контур** — оригинальный пиксель-арт без файлов.
- **Подсветка спрайтов через `emissiveMap` = та же текстура** — враги не тонут в темноте и сохраняют цвета; без карты `emissive` заливал спрайт серым.
- **Смерть — враг разлетается на куски (гибы), кровь и лужу на полу; чемпион сначала «взрывается» серией взрывов** — фирменное ощущение жанра.
- **Пулы для кусков (90), луж (40) и взрывов (16)** — никаких созданий объектов в бою.
- **Снаряды врагов — зелёные «варп»-сгустки, жаровни — анимированный огонь + 4 мерцающих точечных света** — контраст холодного камня и тёплого огня.
- **Витражи — плоскости с прозрачностью вокруг стрельчатой арки, светятся сами (MeshBasic)** — готика без сложной геометрии.
- **Пиксельный шрифт Press Start 2P (есть кириллица) подгружается из скрипта** — если Google Fonts недоступен, игра всё равно стартует сразу, с моноширинным шрифтом.
- **На телефоне панели статуса сверху, на ПК — снизу, как в классических шутерах** — внизу на телефоне пальцы и кнопки.

## Версия 3: «Iron Crusade» по новому CLAUDE.md (гибридный визуал)

- **Название «Iron Crusade», свои фракции и эмблемы (меч в круге у героев, глаз-спираль у еретиков)** — без слов и символов эталона.
- **Окружение рендерится почти в родном разрешении (×1 на ПК, ×0.75 на телефоне, DPR ≤ 2), пиксели — только внутри текстур (NearestFilter)** — так выглядит эталон; рендер всей сцены в 300 px давал «кубизм».
- **Оружие и кровь на экране — отдельный 2D-холст 280 px по высоте, растянутый без сглаживания** — крупные чёткие пиксели спрайтов поверх гладкого 3D; оружие занимает ~40% кадра, как в эталоне.
- **Фабрика пиксель-арта на масках с объёмным затенением** (расстояние до края → нормаль → 4–5 тонов с дизерингом, свет сверху-слева, внутренний и внешний контур) — спрайты не выглядят набором прямоугольников; всё рисуется при запуске, без файлов, поэтому PNG в `assets/` не нужны. Проверка глазами — через `tools/preview.html`.
- **Оружие от первого лица собрано из «призм в перспективе» + латные перчатки, дизеринг на оружии слабее (0.22)** — тона ровнее, как в эталоне.
- **Кадры смерти врагов — поворот кадра «попадание» к земле + лужа крови** — 4 кадра без ручной отрисовки каждого.
- **Враги видны только спереди** — 8 сторон в 5 раз больше арта; на арене почти незаметно.
- **Подсветка спрайтов через emissiveMap = та же текстура** — враги читаются на любом фоне.
- **Физика: коробки с высотой; ступенька до 0.45 м; потолки отдельно от стен; движение шагами ≤ 0.25 м** — прыжки, лестницы, ниша секрета; рывок не проходит сквозь стены даже при низком FPS.
- **Пропасть — «дыра» в земле + невидимая стена для врагов; падение → чекпоинт (последняя твёрдая точка) и 15 урона.**
- **Навигация врагов: «щупальца» + маршруты через две лестницы на платформу + защита от застревания** — без навмеша.
- **Броня поглощает 2/3 урона; подборы поднимают здоровье и броню до 200** — темп эталона: восстановление только подборами.
- **Термокопьё выдаётся после второй волны, плазма лежит на платформе, остальное — с начала** — каждое оружие успевает пригодиться за 5 минут.
- **Удар клинком доступен с любым оружием (кнопка «ближний бой»)** — как быстрый удар в эталоне.
- **Одна кнопка «R» на телефоне: перезарядка, а если нечего перезаряжать — смена оружия; плюс тап по иконке оружия** — меньше кнопок на экране.
- **Свет: полусфера + солнце, плюс пул из 4 точечных огней для вспышек и взрывов (без пересборки шейдеров), «свечение» — аддитивные ореолы** — дёшево для телефона.
- **Туман FogExp2, горы и шпили — плоские цвета дымки без тумана** — светлая атмосферная перспектива как в эталоне.
- **Здоровье босса 2000, призыв фанатиков реже в ярости** — весь бой укладывается примерно в 5 минут.
- **Шрифты (Yanone Kaffeesatz, Press Start 2P) подгружаются скриптом** — если Google Fonts недоступен, игра стартует сразу с системными.
- **Сборка в один файл: каждый модуль в своей области видимости (IIFE), порядок по зависимостям** — без конфликтов имён.
- **Тесты: headless Chromium с подменой CDN на локальную копию Three.js** — песочница иногда не может скачать CDN; сама игра грузит Three.js с CDN.
