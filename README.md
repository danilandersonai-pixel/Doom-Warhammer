# Iron Crusade — прототип

Мобильный ретро-FPS («бумер-шутер»): детальное 3D-окружение с пиксельными текстурами, враги, оружие,
кровь и огонь — пиксельные спрайты. Одна арена, бой волнами и босс — около 5 минут.
Враги, босс и оружие в руках сделаны конвейером «3D-модель → 8 ракурсов → пикселизация → атлас»
(CC0-модели Quaternius, перекрашенные и доработанные, и свои модели оружия). Звуки и музыка генерируются кодом (Web Audio).

## Как запустить

```bash
python3 -m http.server 8000
```

Открой <http://localhost:8000>. Нужен интернет: Three.js загружается с CDN.

**На телефоне:** телефон и компьютер в одной Wi‑Fi сети, открой `http://<IP-компьютера>:8000`.
Держи телефон горизонтально. Нужен iOS 16.4+ (Safari) или свежий Chrome на Android.

**Одним файлом:** `python3 tools/build_artifact.py` собирает всё в `dist/iron-crusade.html`
(так игра опубликована как артефакт).

## Как играть

Орден высадился у осквернённой площади. Иди по золотым меткам к воротам, отбей три волны (5 → 8 → 10),
сокруши Колосса (3 фазы) и уходи через северные врата. На экране завершения — время, убийства и секреты.

| Действие | Телефон | Компьютер |
|---|---|---|
| Бег | левая часть экрана (стик) | WASD |
| Обзор | свайп по правой части | мышь |
| Огонь | большая кнопка с прицелом (можно вести пальцем) | ЛКМ |
| Прыжок / рывок | кнопки ⌃⌃ / ›› | Пробел / Shift |
| Цепной клинок | кнопка с мечом | F или ПКМ |
| Граната | кнопка с гранатой | G |
| Перезарядка / смена оружия | кнопка ↻ (если перезаряжать нечего — смена), тап по иконке оружия | R · 1–5 · колесо |
| Пауза и настройки | лаймовое меню справа сверху | Esc |

Геймпад тоже работает (стандартная раскладка). В настройках: чувствительность, размер и прозрачность кнопок, музыка, гироскоп.

**Оружие:**
1. **Громовержец** — автомат с разрывными патронами.
2. **Молот** — двуствольный дробовик, страшен вблизи.
3. **Звезда** — плазма: медленные сгустки, урон по площади (лежит на платформе).
4. **Термокопьё** — луч, огромный урон вблизи (сбрасывают после второй волны).
5. **Цепной клинок** — ближний бой без патронов, удар доступен с любым оружием.
Плюс **гранаты**.

**Враги:** фанатик (быстро бежит и режет), стрелок (держит дистанцию, стреляет очередями),
тяжёлый демон (медленный, живучий, таранит рывком), **Колосс** — фаза 1: веер огня и удар клешнёй;
фаза 2: ракеты и призыв фанатиков; фаза 3: ярость и огненная спираль.

**Ещё:** аптечки, броня, патроны и гранаты (выпадают и из врагов), взрывные бочки, пропасть на востоке
(падение — возврат на последнюю точку с уроном), **секрет** — тайник за проломом в западной стене (подсказка: ящик у стены).

## Устройство кода

```
index.html, style.css   — страница и интерфейс
src/main.js             — рендер, игровой цикл, попадания и урон, экраны, настройки
src/sprites.js          — загрузка запечённых атласов, выбор кадра по анимации и ракурсу (8 секторов)
src/pixel.js            — фабрика пиксель-арта для мелочей: маски, затенение, контуры
src/art_weapons.js      — вспышки выстрела
src/art_misc.js         — пикапы, иконки, портреты, кровь, куски, огонь, взрывы
src/textures.js         — текстуры окружения 128–256 px (CC0-основа + процедурные детали)
src/level.js            — карта: двор, арена, платформа, пропасть, секрет, ворота, небо, туман
src/physics.js          — коробки-коллайдеры, земля, ступени, потолки, пропасть
src/player.js           — бег, прыжок, рывок, здоровье и броня
src/weapons.js          — логика оружия и отрисовка спрайта в руках
src/projectiles.js      — плазма, гранаты, пули и огонь врагов
src/enemies.js          — враги и босс: ИИ, анимация, трупы, куски
src/pickups.js          — пикапы и бочки
src/flow.js             — задачи, волны, босс, выход, секрет, золотые метки
src/hud.js              — интерфейс
src/audio.js            — звуки и музыка
tools/bake_sprites.mjs  — бейкер спрайтов (запуск ниже), задания — tools/bake/jobs.mjs
tools/bake/             — страница бейкера (three.js), навесные детали (parts.js), модели оружия и рук (fp.js)
tools/make_textures.sh  — CC0-текстуры ambientCG → 256 px с ограниченной палитрой
tools/gdrive.py         — загрузка CC0-паков Quaternius с Google Drive
assets/models/          — исходные CC0-модели (glTF) и их лицензии
assets/sprites/         — готовые атласы PNG + JSON (враги, босс, оружие)
assets/textures/        — пикселизированные CC0-текстуры
tools/build_artifact.py — сборка в один HTML (атласы встраиваются)
tools/preview.html      — просмотр атласов и текстур (?set=chars|misc|tex)
reference/, VISUAL_NOTES.md — эталон и заметки визуальной проверки
```

Для экспериментов в консоли браузера есть `__game.G` — например, `__game.G.player.health = 999`.

## Конвейер спрайтов (3D → 8 ракурсов → пиксели)

```bash
python3 -m http.server 8000 &          # бейкер открывается в браузере с этого сервера
(cd tools/bake && npm install)          # three.js для страницы бейкера
node tools/bake_sprites.mjs             # все задания; или по именам: fanatic boss w_rifle …
```

Нужны Playwright (Chromium) и, по желанию, ffmpeg (сжимает атлас в 8-битный PNG без потерь).
Как это работает: модель грузится в three.js, перекрашивается, на кости навешиваются детали из примитивов,
каждый кадр анимации снимается ортокамерой с 8 направлений при свете сверху-слева и холодном контровом,
кадр рендерится с запасом ×4 и усредняется блоками (пиксели без размытия краёв), затем общая палитра
(k-means, 22–32 цвета) и тёмный контур 1 px. Оружие снимается перспективной камерой игрока (кадр 384×256).
В игре враг — билборд, кадр выбирается по углу между его взглядом и камерой, поэтому при обходе он поворачивается.

## Что можно улучшить дальше

1. **Больше кадров и анимаций** — бег с оружием у стрелка, отдельные «рывки» демона, смерть от взрыва.
2. **Поиск пути (навмеш/A\*)** вместо простого обхода препятствий.
3. **Больше уникального окружения:** подбитая техника детальнее, обломки, лестницы на стены, вторая арена.
4. **Музыка и звук:** настоящие сэмплы, реверберация, разные треки для фаз босса.
5. **Оптимизация под слабые телефоны:** объединение статичной геометрии, авто-снижение разрешения при низком FPS.
6. **Прогресс:** очки, медали за время, сохранение рекорда.
