# Boltgun Prototype

Учебный прототип мобильного шутера от первого лица в духе ретро-шутеров 90-х: пиксельная картинка,
враги-спрайты, взрывы на куски, готическая арена с витражами и жаровнями.
Одна арена, три волны врагов и финальный чемпион — примерно 5 минут боя.
Вся графика нарисована кодом (пиксель-арт на canvas), все звуки генерируются кодом (Web Audio API).

## Как запустить

```bash
python3 -m http.server 8000
```

Открой в браузере <http://localhost:8000>.

**На телефоне:** телефон и компьютер должны быть в одной Wi‑Fi сети.
Узнай IP компьютера (например, `192.168.1.10`) и открой на телефоне `http://192.168.1.10:8000`.
Лучше держать телефон горизонтально. Нужен iOS 16.4+ (Safari) или свежий Chrome на Android.

Нужен интернет: библиотека Three.js загружается с CDN (jsdelivr).

## Как играть

Цель — пережить три волны врагов (5 → 8 → 10) и убить чемпиона.

| Действие | Телефон | Компьютер |
|---|---|---|
| Движение | левая половина экрана (стик появляется под пальцем) | WASD / стрелки |
| Поворот камеры | свайп по правой половине экрана | мышь |
| Огонь | кнопка «ОГОНЬ» (удерживай; можно вести пальцем, чтобы целиться) | ЛКМ (удерживать) |
| Ближний бой | кнопка «УДАР» | ПКМ или F |
| Перезарядка | кнопка «R» (и автоматически, когда магазин пуст) | R |
| Пауза | — | Esc |

- **Броня** принимает урон первой и восстанавливается, если 4 секунды не получать урон. **Здоровье** не восстанавливается.
- **Враги:** красные — бегут и бьют вблизи; зелёные — держат дистанцию и стреляют медленными снарядами (от них можно уклониться); **чемпион** — большой, крепкий, стреляет очередями веером и сильно бьёт вблизи.
- Удар в ближнем бою убивает обычного врага ближнего боя с одного раза и отбрасывает врагов.

## Устройство кода

```
index.html      — страница, HUD, кнопки, подключение Three.js через importmap
style.css       — стили интерфейса
src/main.js     — точка входа: рендер, игровой цикл, стрельба, экраны победы/поражения
src/arena.js    — арена: пол, стены, витражи, знамёна, жаровни, небо, туман, свет
src/sprites.js  — пиксель-арт кодом: спрайты врагов, куски, кровь, взрывы, огонь
src/input.js    — управление: клавиатура/мышь и сенсорный стик/кнопки
src/player.js   — игрок: движение, здоровье, броня, тряска камеры
src/weapon.js   — оружие: модель, огонь, отдача, вспышка, патроны, перезарядка, удар
src/enemies.js  — враги: модели, ИИ, снаряды
src/waves.js    — волны и появление чемпиона
src/hud.js      — обновление интерфейса
src/effects.js  — частицы, трассеры, куски, лужи крови, взрывы (с пулами объектов)
src/audio.js    — процедурные звуки
src/collision.js— простые столкновения (круг против прямоугольников)
DECISIONS.md    — какие решения приняты и почему
```

Для экспериментов в консоли браузера доступен объект `__game`, например:
`__game.player.health = 1000` — бессмертие, `__game.weapon.ammo = 999` — много патронов.

Цифры баланса (здоровье врагов, урон, скорость) лежат в начале файлов
`src/enemies.js`, `src/weapon.js`, `src/player.js`, `src/waves.js` — их удобно менять.

## Что можно улучшить дальше

1. **Подбираемые предметы** — аптечки и патроны, выпадающие из врагов.
2. **Указатель направления урона** — красная дуга со стороны, откуда прилетело.
3. **Навигация врагов** — сейчас простое «обходи препятствие»; можно сделать сетку и поиск пути (A*).
4. **Спрайты с 8 направлений** — сейчас враги нарисованы только спереди; можно добавить вид сбоку и сзади.
5. **Музыка** — процедурный эмбиент или барабаны, ускоряющиеся к чемпиону.
6. **Настройки** — чувствительность обзора, громкость, инверсия оси.
7. **PWA** — установка на домашний экран и работа без интернета (свой экземпляр Three.js вместо CDN).
8. **Больше контента** — второе оружие, новые типы врагов, вторая арена.

## Версия одним файлом (артефакт)

`python3 tools/build_artifact.py` склеивает все модули и стили в один файл `dist/boltgun.html`.
Его можно открыть без отдельных файлов `src/` или опубликовать как страницу (Claude Artifact).
После правок в `src/` пересобери файл этой командой.
